## Current display treatment

The standalone design preview references these filenames directly. Its source-image frames are 44 × 44px on desktop and 40 × 40px on mobile inside the set composition box. Grayscale/contrast and multiply blending remove the pale rectangular appearance against the white card without altering the original files. Judge matching size by the visible artwork, not only source dimensions.

Alignment refinement: tire frame stays 44px desktop / 40px mobile. Wheel frame is 42.5px / 38.6px with a small upward offset (1px / 0.9px), compensating for unequal source padding so the visible artwork's top and bottom align. Dark-pixel source bounds: tire y=24..113 in 163×140; wheel y=23..177 in 234×194.

Show tire-only, tire-and-wheel, or wheel-only according to the set's recorded composition. Accessible names describe the composition without visible extra captions.
